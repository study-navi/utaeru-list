プライバシーポリシー

最終更新: 2026年8月17日

本ページは、2026年8月時点の Utalis の実装（GitHub Pages + Cloudflare Workers + D1）に基づいて記載しています。公開前に必要に応じて法務専門家のレビューを受けてください。

1. 概要

Utalis（うたりす）は、歌える曲リストの作成・公開サービスです。本ポリシーは、本サービスで取り扱う情報について説明します。

2. サーバー（D1）に保存する情報

Cloudflare D1 データベースに、以下を保存します。

  • 公開ページデータ（streamers.public_data）: 配信者名、サブタイトル、選択した曲情報、曲ごとのタグ・状態・新着設定、タグプリセット、テーマ設定、公開ページ ID、設定バージョン、更新日時等（JSON 形式）
  • 公開ページのメタ情報: 公開ページ ID、作成日時、更新日時
  • Google ログイン利用時（users）: 内部ユーザー ID、Google アカウント ID（sub）、メールアドレス、表示名、作成日時、最終ログイン日時
  • Google 管理の紐付け（streamer_owners）: どの Google アカウントがどの公開ページ ID を管理しているか
  • 匿名作成・編集キー管理（streamer_edit_keys）: 編集キーの SHA-256 ハッシュ値（サーバー側の秘密値と組み合わせて計算）。平文の編集キーは保存しません。Google 連携後は無効化（revoked_at）されます
  • 削除済みページ: 公開ページ ID、削除日時（deleted_at）。ソフト削除のため ID 再取得防止のために保持します

3. ブラウザに保存する情報

Utalis のビルダー画面（index.html）では、利便性のため以下をブラウザの sessionStorage に保存することがあります（タブを閉じると消える一時保存）。

  • Google ログイン後に発行されるセッショントークン（API 認証用）
  • 編集キー（匿名作成・編集キー管理を選んだ場合。端末内にのみ保持）

これらは Utalis のサーバー（D1）へ平文で送信されるのは API 利用時のみであり、編集キーの平文は D1 に保存されません。

4. 保存しない情報

以下は、運営統計や分析目的で D1 に恒久保存しません。

  • リスナー（公開ページ閲覧者）の Google アカウント情報
  • リスナーの閲覧履歴・行動履歴
  • 端末情報のプロファイリング
  • 編集キーの平文（サーバー側）

スパム防止のため、書き込み系 API では Cloudflare Workers のレート制限機能により、短時間のリクエスト元 IP が一時的に利用される場合があります（D1 への恒久保存ではありません）。

5. Google ログイン

Google アカウントで管理する場合、Google OAuth（Google Identity Services）により認証します。Utalis は Google からアカウント ID（sub）、メールアドレス、表示名等を受け取り、ログイン状態の管理と公開ページの所有者確認に利用します。

セッションは署名付きトークンで管理されます。GitHub Pages（utalis.github.io）から API（utaeru-api.manabit.workers.dev）へはクロスサイトとなるため、ブラウザの sessionStorage にトークンを保持し、API リクエスト時に送信する方式を用いています。

Google 側の取り扱いについては、Google プライバシーポリシーもご確認ください。

6. 公開データ

公開した曲リストは、固定 URL から誰でも閲覧できる状態になります。リスナーのログインは不要です。公開する内容（配信者名・曲名等）に個人情報や機密情報を含めないようご注意ください。

7. 利用目的

  • 歌える曲リストの作成・公開・更新・削除機能の提供
  • Google 管理・編集キー認証によるページ管理
  • 不正利用・大量作成の防止（レート制限）
  • サービス運営に必要な最小限の集計（公開ページ数、曲数等。個人を特定しない形式）

8. 第三者サービス

  • GitHub Pages: ビルダー画面・公開ページ viewer の配信
  • Cloudflare Workers / D1: API とデータ保存
  • Google: OAuth 認証（Google 管理を選んだ場合）

9. 削除

利用者は公開ページを削除できます。削除後も公開ページ ID の予約のため、識別子と削除日時等は保持されます。詳細は利用規約を参照してください。
