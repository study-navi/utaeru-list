プライバシーポリシー

最終更新: 2026年8月17日

本ページは、2026年8月時点の Utalis の実装（GitHub Pages + Cloudflare Workers + D1）に基づいて記載しています。公開前に必要に応じて法務専門家のレビューを受けてください。

1. 概要

Utalis（うたりす）は、歌える曲リストの作成・公開サービスです。本ポリシーは、本サービスで取り扱う情報について説明します。

2. 収集・保存する情報

本サービスでは、以下の情報を Cloudflare D1 データベース等に保存します。

  • 公開ページデータ: 配信者名、サブタイトル、選択した曲情報、タグ・状態・新着設定、テーマ設定、公開ページ ID、作成日時・更新日時
  • Google ログイン利用時: Google アカウント ID（sub）、メールアドレス、表示名、ログイン日時
  • 匿名作成・編集キー管理時: 編集キーのハッシュ値（平文の編集キーは保存しません）
  • 削除済みページ: 公開ページ ID と削除日時（ソフト削除。ID の再取得防止のため保持）

3. 保存しない情報

以下は、運営統計や分析目的で D1 に恒久保存しません。

  • リスナー（公開ページ閲覧者）の Google アカウント情報
  • リスナーの閲覧履歴・行動履歴の詳細
  • 端末情報のプロファイリング
  • 編集キーの平文

なお、スパム防止のため、書き込み系 API では Cloudflare Workers のレート制限機能により、短時間のリクエスト元 IP が一時的に利用される場合があります。これは D1 への恒久保存ではありません。

4. Google ログイン

Google アカウントで管理する場合、Google OAuth により認証します。Utalis は Google からメールアドレス等を受け取り、セッション管理に利用します。Google 側の取り扱いについては、Google プライバシーポリシーもご確認ください。

5. 公開データ

公開した曲リストは、固定 URL から誰でも閲覧できる状態になります。公開する内容（配信者名・曲名等）に個人情報や機密情報を含めないようご注意ください。

6. 利用目的

  • 歌える曲リストの作成・公開・更新・削除機能の提供
  • Google 管理・編集キー認証によるページ管理
  • 不正利用・大量作成の防止（レート制限）
  • サービス運営に必要な最小限の統計（ページ数、曲数等の集計。個人を特定しない形式）

7. 第三者サービス

  • GitHub Pages: ビルダー画面・公開ページ viewer の配信
  • Cloudflare Workers / D1: API とデータ保存
  • Google: OAuth 認証（Google 管理を選んだ場合）

8. 削除

利用者は公開ページを削除できます。削除後も公開ページ ID の予約のため、識別子と削除日時等は一定期間保持されます。詳細は利用規約を参照してください。
