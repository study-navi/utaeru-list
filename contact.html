お問い合わせ

不具合・削除相談・権利侵害・その他のご連絡

お問い合わせ方法

Utalis は個人運営の無料サービスです。現在、専用の問い合わせフォームやサポートメールは設けていません。以下の GitHub Issues からご連絡ください。

新しいお問い合わせを作成する

GitHub アカウントがなくても、Issues ページからゲストとして投稿できる場合があります（GitHub の設定により異なります）。アカウント作成が難しい場合は、SNS 等で運営者に別途ご連絡ください（返信は運営者判断）。

記載していただきたい内容

  1. お問い合わせの種類（不具合 / 削除相談 / 権利侵害 / その他）
  2. 公開ページ ID（該当する場合。例：sample）
  3. 問題が起きた操作手順
  4. 利用環境（ブラウザ・端末・OS）

編集キーは絶対に記載しないでください。 メールアドレス等の個人情報も、公開 Issues には書き込まないようご注意ください。

種類別の目安

  • 不具合: 画面の表示崩れ、公開できない、編集できない等
  • 削除相談: 自分のページを削除できない、編集キーを紛失した等
  • 権利侵害: 公開ページの内容に関する申告（可能な範囲で確認します）

返信について

Issues は公開されます。個別メールでの対応が必要な場合は、Issues 上でその旨をお知らせください（運営者判断）。返信までにお時間をいただく場合があります。

無料で使える代替案（参考）

運営体制の変更時に検討できる無料の選択肢として、GitHub Issues（現行）、GitHub Discussions、Google フォーム等があります。現時点では Issues を採用しています。
