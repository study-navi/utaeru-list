お問い合わせ

不具合・削除相談・権利侵害・その他のご連絡

GitHub Issues（推奨）

Utalis の不具合報告や機能に関するお問い合わせは、公開リポジトリの Issues から受け付けています。

GitHub Issues を開く（utalis/utalis.github.io）

公開ページ ID、発生した操作、利用環境（ブラウザ・端末）を記載いただけると対応しやすくなります。編集キーは絶対に記載しないでください。

権利侵害・削除相談

公開ページの内容に関する権利侵害の申告、または削除に関する相談も、上記 Issues からご連絡ください。可能な範囲で確認します。

個人情報を含む連絡について

Issues は公開されるため、メールアドレス等の個人情報を本文に書き込まないようご注意ください。個別メールでの対応が必要な場合は、Issues 上でその旨をお知らせください（運営者判断）。

専用の問い合わせフォームやサポートメールは、現時点では設けていません。運営体制に応じて変更する場合があります。
