お問い合わせ方法

不具合や改善のご連絡は、次のフォームからお願いします。サイトから個人情報や画面の内容を自動送信することはありません。

お問い合わせ

削除相談・権利侵害など、フォーム以外のご連絡は GitHub Issues も利用できます。

うたエモは個人運営の無料サービスです。現在、専用の問い合わせフォームやサポートメールは設けていません。次の GitHub Issues からご連絡ください。

GitHub Issues でお問い合わせを作成する

URL: https://github.com/utalis/utalis.github.io/issues/new

GitHub アカウントがなくても、リポジトリの設定により Issues へ投稿できる場合があります（GitHub 側の設定により異なります）。アカウント作成が難しい場合は、Issues 上でその旨を記載してください。

記載していただきたい内容

  1. お問い合わせの種類（不具合 / 削除相談 / 権利侵害 / その他）
  2. 公開ページ ID（該当する場合。例: sample）
  3. 問題が起きた操作手順
  4. 利用環境（ブラウザ・端末・OS）

記載しないでください

  • 編集キー — 絶対に Issues 等の公開場所に書き込まないでください
  • メールアドレス等の個人情報 — Issues は原則公開されます。公開を避けたい場合は、その旨を Issue 内でお知らせください

種類別の目安

  • 不具合 — 画面の表示崩れ、公開できない、編集できない、Google ログインがうまくいかない等
  • 削除相談 — 自分のページを削除できない、編集キーを紛失した、公開ページ ID の問題等
  • 権利侵害 — 公開ページの内容に関する申告（可能な範囲で確認します）
  • その他 — 利用規約・プライバシーポリシーに関する質問等

返信について

Issues は公開されます。返信までにお時間をいただく場合があります。個別対応が必要な場合も、原則 Issues 上でのやり取りとなります。
