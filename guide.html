1. うたエモとは

うたエモは、配信で歌える曲をまとめて、リスナーに見せられるリストを作れる無料サービスです。

作ったリストは固定URL（例：https://utalis.github.io/u/あなたのID）で公開でき、配信の概要欄やSNSに貼って共有できます。リスナーはログイン不要で、曲名検索やランダム選曲などが使えます。

2. はじめ方

うたエモ を開くと、最初にスタート画面が表示されます。次のどちらかで始められます。

Googleでログイン — 公開済みのリストを、別のパソコンやスマホからも 編集する で呼び出して編集できます（下書きのクラウド同期ではありません）。

ログインせずにはじめる — Googleアカウント不要。この端末のブラウザ内に下書きを自動保存しながら作成できます。

スタート後は、上部に5つのタブがあります。スマホでは短い名前で表示されます。

PC：基本情報 ｜ 曲を選ぶ ｜ デザイン ｜ プレビュー ｜ 管理

スマホ：基本 ｜ 曲 ｜ デザイン ｜ 確認 ｜ 管理

おすすめの流れは次のとおりです。順番は固定ではありません。必要なタブを行き来しながら進めて大丈夫です。

  1. 基本 — 配信者名・サブタイトル・公開ページID
  2. 曲 — 歌える曲を選ぶ
  3. デザイン — テーマカラーを選ぶ
  4. 確認 — リスナーから見える見え方をチェック
  5. 公開する — 画面上部のボタンでオンライン公開
  6. 管理 — 必要ならHTMLの復元やタグ候補の編集

画面上部には常に 公開する ボタンと アカウント（スマホでは ☰）があります。

3. 基本

基本情報 タブで、公開ページの土台を入力します。

配信者名・ページタイトル

公開ページのタイトルとして表示されます。必須です。

一言・サブタイトル（任意）

配信者名の下に表示される短い説明です。空欄でも構いません。

公開ページID

公開URLの末尾になります。

例： IDが sample なら
https://utalis.github.io/u/sample

  • 半角英小文字・数字・ハイフン（-）のみ
  • 3〜32文字
  • 先頭・末尾にハイフンは不可。連続ハイフン（--）も不可
  • terms や admin など、サービス用に予約されたIDは使えません

入力すると、正しい形式のとき公開予定URLがプレビュー表示されます。

オンライン公開しない場合（HTMLファイルだけ書き出す場合）は、公開ページIDは空欄でも構いません。

4. 曲を選ぶ

曲を選ぶ タブで、カラオケアプリ「エモカラ」の曲リスト（2026/7/28 時点・約1,950曲）から選びます。

すべて / 選択中

  • すべて — 曲マスター全体から探して選ぶ
  • 選択中 — すでに選んだ曲だけを一覧。各行の 外す で解除できます

曲名検索 / アーティスト検索

検索欄の上で 曲名 と アーティスト を切り替えられます。

  • 曲名 — 曲名で絞り込み
  • アーティスト — アーティスト名や読み（ひらがな）で絞り込み。五十音フィルターと組み合わせ可能

検索欄右の ✕ で検索をクリアできます。

五十音・かな1文字（アーティスト検索時）

アーティスト検索モードの すべて タブでは、あ行〜わ行のチップで絞り込めます。行を選ぶと、さらに「あ」「い」「う…」など1文字単位のフィルターが表示されます。

選択中 タブでは五十音フィルターは表示されません（選んだ曲だけを見るため）。

曲の選び方

  • アーティスト名をタップすると、そのアーティストの曲一覧が開きます
  • 曲名横のチェックで1曲ずつ選択
  • アーティスト行のチェックで、そのアーティストの表示中の曲をまとめて選択

一括操作

  • 表示中をすべて選択 — 今の検索・フィルター結果をすべて選択
  • 表示中の選択を解除 — 表示中の曲だけ選択解除
  • 全曲を選択 / すべて解除 — マスター全体に対する操作（解除時は確認ダイアログあり）

たくさんの曲から探すコツ

  1. アーティスト検索に切り替える
  2. 五十音で行を絞る（必要なら1文字まで）
  3. アーティスト名の一部を検索欄に入力
  4. 見つかったアーティストを開いてチェック
  5. 選択中 タブで選んだ曲を確認

5. 曲ごとの設定

各曲の 設定 を押すと、その曲専用の設定が開きます。

この曲につけるマーク

複数選べます。公開ページでもリスナー向けの目印として表示されます。

  • ⭐ おはこ
  • ❤️ お気に入り
  • 🔰 練習中

自由タグ（複数選べます）

あらかじめ登録したタグ候補から、その曲に付けたいタグを選びます。候補の追加・削除は 管理 タブから行えます。

追加日

「新着」表示に使えます。日付を入れるか 今日にする を押してください。クリア で削除できます。

6. デザイン

デザイン タブで、公開ページのアクセントカラーを選びます。

  • 8色のプリセットから選ぶ
  • ＋ 好きな色 から自由な色を指定
  • 選択中のカラー に、今選んでいる色が表示されます
  • テーマ見本 で、ボタンや選択状態のイメージを確認できます

選んだ色は 確認 タブのプレビューにも反映されます。

7. 確認

プレビュー（スマホでは 確認）タブで、リスナーから見える公開ページに近い表示を確認できます。

未公開の状態でも、今編集中の配信者名・曲数・テーマカラーなどが反映されます。公開前にここで見た目をチェックするのがおすすめです。

8. 公開する

画面上部の 公開する ボタンで、インターネット上に公開します。

公開の流れ

  1. 配信者名・曲（1曲以上）・公開ページIDを入力
  2. 初めて公開するとき、管理方法を選ぶ画面が出ます（Google / ログインなし / 編集キー）
  3. 公開する を押す
  4. 成功すると公開URLが表示されます

公開URL

https://utalis.github.io/u/あなたのID

公開成功画面では、次の操作ができます。

  • 公開ページを見る
  • URLをコピー
  • 共有（対応ブラウザでは共有シートが開きます。非対応の場合はURLコピー）

公開後、画面上部に 公開ページを見る URLをコピー 共有 も表示されます。

ボタンの表示が変わるとき

  • 公開する — まだ公開していない
  • 変更を公開 — 公開済みで、内容に変更がある
  • 公開済み — 公開済みで、変更がない（押せません）

重要： 編集しただけでは公開ページは更新されません。変更を反映するには、もう一度「公開する」（または「変更を公開」）を押してください。

9. 管理方法

アカウント（スマホは ☰）を開くと、公開後の更新方法を選べます。

Googleで管理する

  • Googleアカウントでログインして管理
  • 初回はログイン後、公開ページIDを この公開ページIDを取得する で予約してから公開
  • 別のパソコンやスマホでも、同じGoogleアカウントでログインし、アカウント内の あなたの公開ページ から 編集する を押せば、サーバー上の公開済みデータを読み込んで編集できます
  • Googleログインだけでは、編集中の下書きがクラウドに自動同期されるわけではありません（下書きはこの端末内に保存されます）

ログインせずに作る（編集キー）

  • Googleアカウント不要
  • 初回公開後に 編集キー が表示されます。必ずコピーして保管してください
  • 次回からは公開ページIDと編集キーで再編集

編集キーを使う

すでに編集キーを持っている場合。公開ページIDと編集キーを入力し 編集を開始 します。

どちらを選べばいい？

  • Googleアカウントを普段使っている → Googleで管理
  • とにかく手早く1回公開したい → ログインせずに作る
  • 以前作ったページを編集したい → 編集キーを使う / Googleでログイン

匿名で作ったページは、あとから Googleアカウントに連携 することもできます（連携後は旧編集キーは使えなくなります）。

10. 編集キー

編集キーは、Googleログインなしでページを更新するための合言葉のようなものです。

  • いつもらう？ — 「ログインせずに作る」で初回公開した直後
  • どこで使う？ — アカウント → 編集キーを使う → IDとキーを入力 → 編集を開始
  • 保管 — メモ帳など安全な場所にコピーして保存。再表示はできません
  • なくした場合 — その編集キーでは更新できません。Google連携済みならGoogleログイン、未連携の場合は運営に相談が必要になることがあります

11. 公開後に編集する

Googleで管理している場合

  1. うたエモ を開き、アカウント → Googleでログイン
  2. あなたの公開ページ に表示されたページの 編集する を押す（サーバー上の最新公開データが読み込まれます）
  3. 曲やデザインを変更
  4. 変更を公開 を押す

編集中の内容がある状態で 編集する を押すと、確認のうえ公開済みデータで置き換わります。ログインしただけでは自動的には読み込まれません。

編集キーで管理している場合

  1. アカウント → 編集キーを使う
  2. 公開ページIDと編集キーを入力 → 編集を開始
  3. サーバー上の最新の公開内容が読み込まれます
  4. 変更後、変更を公開 を押す

編集キーで 編集を開始 すると、端末に残っていた未公開の編集内容は、サーバー上の公開済みデータで置き換わります。ローカルで試し書きしていた内容がある場合は注意してください。

12. 公開ページを削除する

Google管理または編集キー認証済みの状態で、アカウント内の 公開ページを削除 から削除できます。

  • 削除すると、そのURLから曲リストは見られなくなります
  • 確認のため、同じ公開ページIDの入力が求められます
  • 削除した公開ページIDは、他の人も含めて再取得できません

13. 管理タブ

上部タブの 管理 には、次の機能があります。

以前のファイルから復元

過去に HTMLファイルを書き出す で保存したファイルを選ぶと、曲・テーマ・タグなどを読み込んで編集を続けられます。

タグの候補（任意）

曲に付けられるタグの候補リストを編集できます。追加・削除が可能です。

HTMLファイルを書き出す

画面下部の HTMLファイルを書き出す で、オフライン用のHTMLをダウンロードできます。オンライン公開とは別の保存方法です。書き出したファイルは 管理 タブから復元できます。

14. リスナー側の使い方

公開ページ（/u/ID）を開いた人向けの機能です。ログインは不要です。

  • 曲名・アーティスト名で検索 — 1つの検索欄から曲名・アーティスト名・読みを横断検索
  • 五十音（あ行〜わ行） — アーティストの頭文字で絞り込み
  • マークで絞り込み — ⭐ おはこ / ❤️ お気に入り / 🔰 練習中
  • 🆕 新着 — 追加日が新しい曲だけ表示（配信者が追加日を設定している場合）
  • タグで絞り込み — 配信者がタグを設定している場合
  • 🎲 表示中からランダム — 今表示されている曲の中から1曲をランダム表示

各曲には、配信者が設定したマークやタグが表示されます。

15. 困ったとき

Q. 曲が見つからない

曲名検索とアーティスト検索を切り替えてみてください。アーティスト検索では五十音フィルターも使えます。マスターにない曲は選べません。

Q. 公開ページIDが使えない

3〜32文字、半角英小文字・数字・ハイフンのみか確認してください。すでに誰かが使っているID、予約語（terms など）、削除済みのIDも使えません。別のIDを試してください。

Q. 編集キーをなくした

編集キーは再表示できません。Google連携済みならGoogleログインで更新できます。未連携の場合は、お問い合わせ から相談してください。

Q. Googleログインできない

ブラウザのポップアップブロックを確認し、もう一度 Googleでログイン を試してください。ログイン後も 公開する は別操作です。ログインだけでは公開されません。

Q. 公開ページが表示されない

URLが正しいか、公開が成功しているか確認してください。削除されたページは表示されません。

Q. 変更が公開ページに反映されない

編集後に 変更を公開 を押しましたか？ 入力しただけでは更新されません。ボタンが「公開済み」のときは、内容に変更を加えてから再度公開してください。

Q. 曲を間違えて外した

すべて タブで再度検索して選び直せます。公開前ならそのまま選び直し、公開後なら選び直して 変更を公開 してください。ページを再読み込みすると、未公開の変更は失われることがあります。

Q. 公開ページを削除したい

Google管理または編集キーで認証したうえで、アカウント内の 公開ページを削除 から行えます。削除後は同じIDを取り戻せません。

16. 保存について

うたエモ では、編集中の内容はこの端末のブラウザ内に自動で下書き保存されます。一方、リスナーが見る公開ページは「公開する」を押したときだけ更新されます。

下書き自動保存（この端末内）

  • 配信者名・曲の選択・デザイン・曲マーク・自由タグなど、編集内容は この端末のブラウザ内 に自動保存されます
  • 画面に 「この端末に下書き保存済み」 と出ることがあります。これは 公開済み ではなく、端末内の下書きです
  • ページを再読み込みしたり、タブを閉じて再度開いても、下書きがあれば復元されます
  • 別の端末や別のブラウザには自動では同期されません
  • 公開ページは、下書き保存だけでは更新されません

「公開する」を押したとき

オンライン公開に成功すると、内容がサーバーに保存され、リスナーが /u/ID で見られるようになります。ここが公開データの保存タイミングです。

クラウドへの自動保存はありません

編集内容が自動的にクラウド（サーバー）へ送られることはありません。「公開する」を押すまで、リスナー側のページは変わりません。

Googleログインしたとき

  • ログイン前に入力していた内容は、同じタブのままログインした場合、画面上はそのまま残ります（ログイン操作自体で消えません）
  • ログインしただけでは、編集内容がサーバーに保存されるわけではありません
  • 公開するには、引き続き 公開する を押す必要があります

自分でバックアップする方法

  • HTMLファイルを書き出す — 端末にファイル保存。後から 管理 タブで復元可能
  • 公開する — オンライン公開（本番の保存方法）
