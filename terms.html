本利用規約（以下「本規約」）は、うたエモ（UTAEMO）（以下「本サービス」）の利用条件を定めるものです。本サービスを利用する方（以下「利用者」）は、本規約に同意したうえでご利用ください。

1. サービス内容

本サービスは、配信者・歌い手・VTuber 等が「歌える曲リスト」を作成し、固定 URL（https://utalis.github.io/u/{公開ページID}）で公開・共有できる無料の Web サービスです。

主な機能は次のとおりです。

  • 曲マスターからの曲選択、タグ・状態（⭐ おはこ / ❤️ お気に入り / 🔰 練習中 等）の設定
  • 端末内への下書き自動保存（ブラウザの localStorage）
  • オンライン公開（Cloudflare Workers API 経由でサーバーへ保存）
  • 公開ページの閲覧（リスナーはログイン不要）
  • Google ログインによるページ管理、または編集キーによる匿名管理

現時点で有料プランや課金機能はありません。

2. 利用条件

  • 利用者は、自己の責任において本サービスを利用するものとします。
  • 未成年者は、保護者の同意を得たうえで利用してください。
  • 本サービスの利用にあたり、虚偽の情報を登録したり、他人になりすましたりしないでください。

2-1. 管理方法

公開ページの作成・更新・削除には、次のいずれかの方法を選びます。

  • Google ログイン — Google アカウントでログインし、所有する公開ページ ID を管理します。別端末からも、同じ Google アカウントで再編集できます（下書きのクラウド同期機能はありません）。
  • 匿名作成（編集キー） — Google アカウントなしで初回公開できます。発行された編集キーを端末内に保存し、再編集に使います。編集キーを紛失すると、Google 連携前のページは更新できなくなる場合があります。
  • 編集キーによる再編集 — 公開ページ ID と編集キーを入力して、匿名作成したページを更新できます。
  • HTML 書き出し — オンライン公開せず、HTML ファイルとして保存することもできます（この場合、サーバーへの保存は行われません）。

3. 公開ページ ID

オンライン公開する場合、利用者は半角英小文字・数字・ハイフンのみからなる公開ページ ID（3〜32 文字）を設定します。admin、api、terms 等、サービス運用上予約された ID は取得できません。

公開ページ ID は URL の一部となり、第三者からも閲覧可能です。推測されにくい ID の利用を推奨します。

4. 利用者が公開・登録する情報

利用者が公開する配信者名、サブタイトル、選択した曲（曲名・アーティスト名・読み等）、タグ、状態、テーマ設定等は、公開 URL からインターネット上で閲覧可能になります。

公開内容に、本人以外の個人情報、連絡先、編集キー、パスワード等を含めないでください。

5. 曲データについて

本サービスの曲選択画面で使える曲リストは、Mirrativ 内カラオケアプリ「エモカラ」の楽曲一覧（個人配布 Google Drive、2026/7/28 時点）を参照しています。配信状況やアプリ仕様の変更により、実際に歌える曲は変動する場合があります。

曲名・アーティスト名等の権利は、各権利者に帰属します。本サービスは、権利者の許諾を得た楽曲データベースを提供するものではなく、利用者がリストとして整理・公開するための機能を提供します。

8. 下書き・データの保存

編集中の内容（曲選択、タグ、デザイン等）は、原則として利用者のブラウザ内（localStorage）に自動保存されます。これは端末内の下書きであり、Google アカウントのクラウド下書きではありません。別端末へ自動同期されず、ブラウザのデータ削除や端末故障等により失われる場合があります。

オンライン公開後のデータはサーバー（Cloudflare D1）に保存されます。公開操作を行うまで、リスナー向け公開ページは更新されません。

運営者は、データの永続保存や復旧を保証しません。

9. 公開ページの削除

利用者は、Google 管理または編集キー認証により、自身の公開ページを削除できます。削除時には、公開ページ ID の再入力確認が求められます。

削除後、その URL からは曲リストを閲覧できなくなります（HTTP 410 相当の応答）。

削除はソフト削除方式です。公開ページ ID、削除日時、およびサーバー上の公開データ JSON 等は、第三者による ID の再取得防止等のため保持される場合があります。削除した公開ページ ID は、原則として同じ利用者を含め再取得できません。

Google ログインのアカウント情報（メールアドレス等）は、ビルダー画面のアカウント設定から削除できます。所有している公開ページがある場合は、先に各ページの Google 管理を解除してください。公開ページの削除（第 9 章）とは別の操作です。Google ログアウトは端末上のログイン状態を解除するだけで、サーバー上のアカウント情報は残ります。
