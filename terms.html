最終更新: 2026年8月17日

本ページは Utalis の実際の機能に基づく運用上の参考情報です。公開前に必要に応じて法務専門家のレビューを受けてください。

1. サービス概要

Utalis（うたりす）は、配信者・歌い手・VTuber 等が「歌える曲リスト」を作成し、固定 URL（/u/{公開ページID}）で公開・共有できる無料の Web サービスです。現時点で有料プランや課金機能はありません。

2. 利用条件

  • 利用者は、自己の責任において本サービスを利用するものとします。
  • 未成年者は、保護者の同意を得たうえで利用してください。
  • Google ログイン、匿名作成（編集キー）、編集キーによる再編集など、Utalis が提供する管理方法のいずれかを選んで利用できます。

3. 禁止事項

以下の行為を禁止します。

  • 法令または公序良俗に反する内容の公開
  • 第三者の権利（著作権、肖像権、商標権等）を侵害する内容の公開
  • なりすまし、虚偽の配信者名・説明による第三者の誤認を招く行為
  • 短時間での大量ページ作成など、サービス運営を妨害する行為
  • 本サービスの API やデータベースへの不正アクセス、改ざん、削除の試み
  • その他、運営者が不適切と判断する行為

4. 投稿・登録データ

利用者が公開する配信者名、サブタイトル、曲リスト（曲名・アーティスト名等）、タグ、状態、テーマ設定等は、公開ページを通じてインターネット上で閲覧可能になります。公開範囲と内容を理解したうえで投稿してください。

曲データの元情報については、公開ページ内に記載のとおり、Mirrativ 内カラオケアプリ「エモカラ」の楽曲一覧（個人配布 Google Drive、2026/7/28 時点）を参照しています。配信状況や仕様変更により、実際に歌える曲は変動する場合があります。

5. 削除・ID予約

利用者は、Google 管理または編集キー認証により、自身の公開ページを削除できます。削除後、その URL からは曲リストを閲覧できなくなります（HTTP 410 相当の応答）。

削除はソフト削除方式です。公開ページ ID と削除日時等は、第三者による ID の再取得を防ぐため保持されます。削除した公開ページ ID は、原則として同じ利用者を含め再取得できません。

6. アクセス制限

不正利用防止のため、書き込み系 API にはレート制限（短時間のリクエスト回数制限）が設定されています。制限を超えた場合、一時的に操作を受け付けないことがあります。公開ページの閲覧（GET）にはこの制限は通常適用されません。

また、admin、api、terms 等、サービス運用上予約された公開ページ ID は取得できません。

7. サービスの変更・停止

運営者は、事前の通知なく、本サービスの内容変更、一時停止、または終了を行う場合があります。無料サービスであるため、可用性や永続性を保証するものではありません。

8. 免責

本サービスは「現状有姿」で提供されます。運営者は、本サービスの利用または利用不能により生じた損害について、法令上認められる範囲を超えて責任を負いません。

公開ページの内容の正確性、第三者サイト（Google 等）の可用性、通信障害等について保証しません。

9. 問い合わせ

不具合・削除相談・権利侵害その他のお問い合わせは、お問い合わせページをご覧ください。
